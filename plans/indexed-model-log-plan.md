# 模型日志引用化施工方案

状态：已实现并完成离线验收。范围是 RSA 额外保存的模型、工具与通信日志及其消费者。OMP 本体、原生 session/blob、真实模型请求、重试与控制权不改；旧日志和 workspace 数据不批量迁移或删除。

## 目标与存储职责

感知时空轴保存感知原件，执行事件描述谁在何时使用它，模型档案保存消息与请求的结构。相同媒体不再进入 RSA payload/stream；重复消息跨请求、跨 run 引用共享对象。Dashboard 按需展开消息，默认不读取媒体字节；Pet 继续消费 Dashboard 增量协议。

新增 workspace `.rsa/archive/objects/<sha>.json.gz`，只存日志结构与文本，不建立另一套媒体仓库。沿用文件存储，无数据库、额外服务、全量内存索引或新执行框架。原有 `.rsa/timeline/` 负责持久媒体和临时窗口。OMP 自身的全局 blob 仍属于其恢复契约，本次不宣称消除这一份。

## 公共引用契约

- 事件的 artifact 引用使用版本化 `encoding: "rsa-json-v1"`、对象相对路径、存储 hash 和原始 JSON 字节数；stream 的小根节点可内联在引用中，仍校验同样的 hash。旧 `encoding: "gzip"` 仍可读取。
- 对象文件用显式 tagged JSON 节点，标量、数组、对象、对象引用、媒体引用分别编码。原始用户对象不插入 `$ref` 等保留字段，合法同名键及 `__proto__` 不误判。
- 数组逐项、对象逐字段递归；大子结构与大字符串独立寻址，小节点内联。共同消息、工具定义和正文不随每次请求复制。只去重同值，不合并语义相近的消息。
- 媒体节点保存实际字节 hash、长度、媒体类型、表示形式及明确的 timeline asset。资产身份与采样记录身份分开；同一媒体多次采样不能推断为同一条记录。
- 识别模型/API 的 image/audio、data URL 等原生媒体字段，以及工具文本中 JSON 编码的对应媒体字段；未知普通文本仍按文本保存。未录制媒体不自动落盘，保留 hash/大小及不可恢复原因。
- 公共 codec 与文件 reader 使用 Node 标准库，RSA 和 Dashboard 共用同一契约；路径仅从已知 workspace/run 根解析，拒绝路径穿越与符号链接逃逸。先原子发布对象，再写引用事件。对象写失败不能留下看似成功的引用。

## 派生媒体

在有明确观测来源的编码位置登记模型实际使用的版本。重编码后的 bytes 与原件相同则直接引用；不同则由现有感知 writer 保存为同一时空轴中的派生资产，并保留 source asset/record 与转换说明。不能按最近观测或时间邻近猜来源。

常驻 writer 仍是 timeline 唯一写入者。非持久窗口中的派生版本也在窗口中，不能升级成永久对象；窗口淘汰后完整读取明确报过期。普通 native read/bash 图片若无明确来源，仅可按实际字节匹配已有资产，否则标记未录制。完整模型返回不受档案是否可恢复影响。

## 模型与通信写入链路

1. `EventLog` 在真实 workspace host 下启用共享 archive；独立旧格式 fixture 与旧文件保持可读。事件的 ID/trace/epoch、时序、usage 和耗时字段保留。
2. `onPayload`、最终 AssistantMessage、tool update/end、后台结果全部通过同一 archive，不修改实际传给 OMP 或 provider 的对象。
3. WS/SSE stream 保存一次 data 引用和轻量 framing 信息。`raw` 内重复的 data 行变成位置/前缀描述，保留注释、event/id/retry 等信息。非 JSON 帧及 `[DONE]` 按文本保留。出站大正文复用请求内容对象。编码后的根节点不超过 2 KiB 时内联，避免 token delta 造成大量小文件；大子节点仍共享。
4. HTTP 与压缩 HTTP 的 body 同样走 archive；已知 JSON/gzip JSON 保存解析后的语义内容与原 wire hash/长度/编码。JSON 语义重建不冒充压缩后的网络字节逐字还原。非 JSON 文本保留文本，无法解释的二进制只保留明确诊断元数据，不暗建媒体副本。
5. 原生 telemetry 继续 `captureMessageContent=none`。不新增在线诊断，不改重试和请求预算。

## 读取与产品行为

- reader 提供完整读取与媒体引用读取。完整读取遇缺对象、未录制或过期媒体时明确失败；不返回伪造的空图。展示读取保留媒体引用，展开文字不加载图片。
- Dashboard 的一次性和增量 stream reader、工具结果 reader 都兼容新旧引用。出站请求仍不作为新思考/文本展示，也不为投影去展开整个历史请求。缓存版本更新，派生缓存不落媒体字节。
- benchmark 的工具终态读取接入同一 reader；不能因新引用判定后台启动为完成或吞掉真实失败。分析器继续从 events 计算统计，不需要读所有正文。
- 提供离线 CLI 读取事件引用，默认展示媒体引用，显式完整读取才解析媒体。按输入 run 的 manifest 定位 workspace，不接受任意根目录注入。

## 验证与交付

先用临时 workspace 验证，再做源码审查与提交；不重启真实游戏、不调用在线模型、不改 AI 自建文件。

- JSON 特殊键、嵌套字符串、已知媒体表示的往返与引用完整性；共享历史跨请求/跨 run 只新增差异结构。
- 感知原图、实际重编码版本、多个来源同图、未录制和临时窗口过期；检查 archive 无媒体 base64 副本。
- WS full/delta、SSE、HTTP、压缩请求、重试、后台晚到、失败及取消：实际 provider 输入和控制逻辑不变。
- stream 单条 data/raw 去重，framing 保留；旧日志投影和新日志得到一致文本、工具与状态。Dashboard 不展开出站正文、不加载媒体，Pet 无需新协议。
- benchmark 消费工具结果仍判断真实完成状态；离线读取能追溯完整或明确不可恢复的记录。
- 使用已有大日志的有限、流式样本转换到临时目录，比较旧/新字节数、共享对象数和重建内容 hash；不直接改原日志。报告区分 fixture 压缩收益、历史样本收益与尚未证明的长时运行内存。
- 运行相关组件离线测试和类型检查，确认 OMP patches、锁文件与真实 workspace 未改。同步现行 logging 文档，本计划记录最终验收与限制。

## 实施验收（2026-10-27）

已贯通 EventLog、模型/HTTP/流/压缩追踪、工具与后台结果、Dashboard、benchmark evaluator 和离线分析器。压缩完成事件中的 replacement history 也进入引用，不能继续绕过 archive 写进 events。工具参数以 `argsRef` 保留，分析器只为技能路径证据按需解读 read/edit/write 参数；读取失败标明未知，不把技能使用数假报为零。

共享 codec 的测试覆盖特殊键、跨 run 去重、媒体不同表示、合法 JSON 转义、临时过期、坏 hash、目录被换成符号链接，以及离线 CLI 无宿主运行。派生媒体通过唯一 writer 保存，覆盖持久/临时源、冷历史、实际 resize/终端 decoder 和来源缺失。真实 provider 入参、响应、重试及控制对象没有替换。

- RSA：类型检查通过，完整 Bun 测试 220 通过、3 项真实设备测试跳过；Python history/timeline 测试 22 通过。
- Dashboard：类型检查、完整 131 项测试通过；隔离副本 production build 通过，真实 `.next` 未覆盖。已有动态文件路径追踪警告保留。
- 无模型 API 调用、设备接管、服务重启或旧数据迁移。OMP patches、依赖锁文件和 Agent 自建文件未改。

离线重放取自马造 run `2026-10-26T09-37-03.768Z`：顺序读取其中 541 份可解析 JSON payload，以及 136 个 stream 文件中的 16,393 条事件。另 4 份不能直接解析为 JSON 的历史 payload 不计入比较。将已知媒体字节写到临时 fixture 时空轴后，所有 16,934 个 JSON 值完整还原并核对规范序列化 hash；这只证明 codec 往返，不声称旧日志原本就有这些来源引用。原始日志只读，临时数据已清理。

| 这组样本（十进制 MB） | 字节数 |
| --- | ---: |
| 旧 JSON payload + stream | 79,807,707 |
| 新共享日志对象 + stream | 23,188,215 |
| 临时 fixture 中唯一媒体，74 份 | 3,906,228 |
| 新日志加这份媒体 | 27,094,443 |

同范围日志减少约 71%；把唯一媒体也计入后减少约 66%。收益不包含 events、OMP 原生 session/blob、Dashboard 缓存或整个 workspace。重放约 6.4 秒、进程峰值 RSS 约 230 MiB；这是有限离线样本，不是长时宿主或 Next 内存上限。

初次测量发现每个小 stream 根对象单独落盘会产生 18,948 个对象文件，实际磁盘块占用放大；改为上述小节点内联后为 2,707 个对象文件，对象逻辑大小约 3.7 MB、实际分配约 11.8 MB。文本共享仍有索引/文件开销，不能只用 gzip 字节数推断磁盘占用。

尚未做新版本真实长时游玩。新宿主下次启动才启用写入契约；已有日志不会自动变小。OMP 自身仍按其原生恢复约定保存数据；未录制/过期媒体无法完整回放，未知后续重编码不能猜来源；JSON 语义还原也不承诺网络压缩字节逐字还原。共享对象暂不做垃圾回收，删除单个 run 不会回收仍可能被其他 run 使用的对象。
