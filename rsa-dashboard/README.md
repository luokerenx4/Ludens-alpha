# RSA Dashboard

默认通过浏览器使用的运行、回放、Benchmark 和 Ludens Pet 控制台，读取运行日志并提供统一的数据投影和工作区选择。网页运行无需 Electron；可选 Ludens Pet 桌面端加载同一份控制台。

- [安装与工作区启停](../docs/tutorials/quickstart.md)
- [控制台调试与验证](../docs/tutorials/debugging-and-verification.md#独立组件与控制台)：站内文档浏览（`?view=docs`）、工作区能力目录（`?view=caps`）与全局设置（`?view=settings`，含 Ludens Pet 偏好）
- [Loop 注入实验台](../docs/reference/architecture.md#1-omp-超集装配与外层续轮)：开发者面板（`?view=dev&panel=loop`）里模拟一次接管的上下文构成，对照 OMP 原生层、RSA 注入层与已删除的批次末注入通道
- [日志与调用链](../docs/reference/logging.md)
- [UI 组件与主题约定](../docs/reference/dashboard-ui.md)：shadcn/ui、Tailwind CSS 4 与共享控件
- [Benchmark](../docs/reference/benchmark.md)
- [架构与边界](../docs/reference/architecture.md)
