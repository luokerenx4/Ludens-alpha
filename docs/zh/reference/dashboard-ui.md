# Dashboard UI

Dashboard 使用 Next.js App Router、React、Tailwind CSS 4 与 shadcn/ui（Radix / New York）。网页和可选 Electron 桌面端使用同一份组件，不需要启动 Electron 才能开发 UI。

## 组件归属

- `rsa-dashboard/components/ui/` 保存通过官方 shadcn CLI 引入的组件源码。按钮、表单、开关、复选框、单选组、滑块、卡片、表格、对话框、反馈与页内标签应复用这里的原语。
- shadcn/ui 源码采用 MIT License，许可文本保留在 [`licenses/shadcn-ui.txt`](../../../licenses/shadcn-ui.txt)。
- 业务组件仍放在 `components/`；运行时间轴、活动证据、图表和桌宠动画由业务组件实现，不往 UI 原语里加入工作区或 RSA 调用。
- 类名合并使用 `import { cn } from "cn"`，变体用 `class-variance-authority`；它们与当前 shadcn 注册表生成的源码保持一致。

`components.json` 记录注册表风格与路径。需要新组件时在 Dashboard 目录运行，例如：

```bash
cd rsa-dashboard
npx shadcn@4.23.0 add dialog
```

只添加当前使用的组件。生成后审阅源码与锁文件，不用 `--overwrite` 覆盖本地修改。当前本地调整包括 `NativeSelect.wrapperClassName`（控制包装层宽度）以及 Slider 将可访问性名称与描述传给真正可聚焦的 Thumb。Card 使用适合控制台的紧凑默认值：20px 内边距、16px 区块间距与 13px 说明文字。

## 主题与样式

`app/globals.css` 引入 Tailwind 和 `tw-animate-css`，通过 `@theme inline` 将现有 Ludens 深色配色映射到语义 token。根布局固定使用 `dark`，当前没有新增主题切换功能。

| 用途 | 推荐类名 |
| --- | --- |
| 页面与主文字 | `bg-background text-foreground` |
| 卡片和浮层 | `bg-card` / `bg-popover` |
| 主操作 | Button 默认变体，使用 `primary` 金色 |
| 次操作与弱背景 | Button `secondary` / `outline` / `ghost`；`bg-muted` |
| 说明与状态 | `text-muted-foreground` / `text-success` / `text-destructive` |
| 边框、键盘焦点 | `border-border` / `ring-ring` |

注意 `--muted` 表示弱背景，文字使用 `--muted-foreground`。已有领域 CSS 放在 `@layer components`，允许 Tailwind 的 `utilities` 层覆盖；不要新增未分层的全局 `button` / `input` / `select` 样式，否则会压过共享控件的状态、尺寸和焦点样式。

工作区管理、设置、Benchmark、Capabilities、Docs、活动流、请求详情、回放控件与 Loop Lab 使用共享原语。时间轴刻度、图表、证据行和媒体等领域布局保留在业务 CSS 中，周边表面与状态色使用主题 token。

视觉基线是暖炭灰底色、克制的金色操作、轻边框与统一卡片间距。设置优先展示控制台偏好。桌宠关注区域将已保存工作区与观察到的桌面端状态分开展示。此窗口的可选桌面控制有独立的可用性区域，桌面偏好卡片从 1100px 起使用双列；窄屏使用单列。相关控件放在一起，允许翻译后的标签换行；参考生成图调整界面时，必须用真实中英文页面检查桌面和窄屏排版。

运行分析优先呈现请求检查，再展示汇总性能。桌面端将请求列表与详情并排；窄屏使用带标签的请求选择器和较早/较新请求按钮，详情紧随其后。指标与趋势图保留在次要折叠区。缺少测量值时，图表会说明原因而不是只画空坐标轴；记录中的零值、只有等待时长的延迟和数据缺口仍保留各自含义。

在同一工作区路径、运行、周期和分页内切换请求时，请求控件会保持显示，让详情单独加载。详情只属于精确匹配的读取和请求 ID；加载中、失败或找不到的选择不能把上一条请求冒充为新选择。读取失败提供显式重试，重试成功仅在用户尚未移开焦点时恢复焦点；切换工作区、运行、周期或分页不能保留其他范围的内容。

工作区入口采用可搜索的列表，新建、添加已有目录和修改默认位置分别在对话框内完成。高级字段折叠展示，社区驱动字段由已验证的 manifest 决定，并预览最终位置。写入完成后，即使后续目录刷新失败，也应保留成功状态；使用返回的身份显示确认信息并导航。

默认位置修改返回已提交的 `{ config }`；移除返回 `{ removed }`，包含加锁后实际删除的登记项，原本已不存在则为 `null`。界面先应用这些操作结果，再独立刷新目录；重试读取不会重复写入。撤销使用返回的路径，不使用过期列表行。注销前，CLI 与 Dashboard 共用的操作仅清除指向该工作区的桌宠目标。目标清理失败时保留登记，用户修复问题后可显式重试。成功移除后，重新登记目录不会恢复旧跟随。

工作区选择放在共用的顶部上下文栏。桌面端的导航与可选桌宠面板共用中间滚动区，设置保留在独立的左下角页脚。较矮的窗口和较长的桌宠状态提示不能把导航挤没；键盘焦点到达链接或操作时，相应条目会滚入可见区域。宽度在 680px 及以下时，菜单将导航、桌宠面板和设置展开为正常页面内容。跨越该断点时，只在当前侧栏控件变为隐藏的情况下转移焦点。

工作区选择器打开一个高度受限的弹窗，候选按钮在选择前展示完整名称和目录；目录数据缺失时使用真实工作区 ID。当前选中项和不可用目录有明确标识，不可用条目仍可选择。候选列表单独滚动，标题与关闭按钮保持可见。打开、关闭或选择当前工作区不会改变导航；选择其他工作区时，通过既有范围重置导航提交其精确 ID。目录列表变化会更新候选项，选择器不会自动提交选择；父页面保留既有的上下文回退规则。关闭后焦点回到顶部入口。

运行记录使用同样的有界选择面板。每个已记录候选项在选择前展示完整 ID，只有合法的标准时间戳前缀才附带可读时间。时间摘要包含年份和秒，并明确采用 Asia/Shanghai 时区；自定义或形似时间戳但非法的 ID 保持原样，不会被归一化成日期。独立的“最新运行”入口保留空值行为，与显式选择对应的历史运行不同。精确选中值、目录顺序、Benchmark 标记和原有导航保持不变。工作区与运行选择器共用关闭、滚动和焦点行为。

设置在浏览器中即可使用，无需 Electron。语言位于最前，关注工作区仍通过服务端提供。可选桌面区域只在显式检查及窗口焦点、可见性变化时检查当前窗口的桥接，不会启动桌面应用，也不会把服务端消费端的连接视为本地桥接。可见性、声音和通知在读取前保持未知，不会显示为禁用的默认值。读取失败会保留并标注缓存值，提供只读重试。无法确认结果的写入不会重放；再次修改前需重新读取设置。桥接生命周期、操作标识和更新的订阅值共同保护读取、写入、文件验证与声音预览，防止桥接替换或断开后的迟到结果污染当前状态。

桌宠关注选择器即时保存，保存期间保留焦点。目标 PUT 返回精确提交的 `{ target }`，桌宠心跳 POST 返回 `{ consumer }`，两种回执都不依赖后续读取。界面先应用目标回执，再独立读取桌面端状态。心跳读取失败仍保留目标，并将连接状态标为未知；完整读取失败则保留并标注已保存或缓存的选择。保存响应缺失时保持“尚未确认”，同时显示请求目标与上次确认的目标，在显式读取成功前禁止其他更改。恢复操作不会重复写入。路径与原始错误按需展开。已保存选择、桌面连接与应用状态是不同事实：`targetRevision` 表示正在尝试的选择，`revision` 表示已加载的来源，因此旧错误不会归到新选择。离线或失去登记的目标仍以 `targetUnavailable` 保留展示；桌面端停止消费该来源而不清除选择，恢复可用后可以重新连接。 首次保存之前，选择器显示尚未设置。显式选择**停止跟随**会保存 `null`，使后续 `ifUnset` 启动无法自动选择工作区。

感知页采用精确数值输入、预设、辅助滑条及明确的覆盖/继承来源。草稿按工作区身份与登记路径隔离，并保留在当前标签页；保存、重新读取与检查运行进程分别操作。只有当前工作区宿主的可靠观测才能提供运行值，不推断继承值来源。可复制的重载命令包含工作区，并清除继承的 socket 覆盖；页面不会执行命令。详见[感知配置与恢复](../tutorials/perception-and-action.md)。

继承规则统一显示在字段上方。每项保留用途与来源选择器，选择继承时显示该项明确标注的内置默认值。这些默认值是回退值，不是运行进程的观测证据。已保存设置与运行观测保持为独立区域，宽屏并排、窄屏堆叠，保留读取与恢复操作。

能力目录用同一份语义列表展示评测任务：宽屏按列对齐，手机端纵向排列并使用完整宽度。每项的名称与说明保持在一起，可按需展开完整内容摘要，并通过当前工作区、任务名和摘要准确链接到 Benchmark 中的对应任务。缩放时保留同一控件和展开状态。能力接口不包含任务声明版本，应到对应任务的 Benchmark 面板读取。任务来源状态、诊断、缓存读取提示和通用 Benchmark 入口与这些链接分别保留。

设备与工作区能力声明在各自来源卡片内使用独立的响应式列表。每条声明的完整标识符、说明和带标签的控制信息保持在一起；容器较窄时纵向排列，无需横向滚动。需要接管与只读声明相互独立，未知值不会根据标识符或来源推断。来源状态、快照信息、诊断数量、缓存读取提示和显式刷新保持原有含义；读取声明不代表验证或执行该能力。

Benchmark 目录使用同一个工作区上下文。切换工作区会清除此前的任务、结果和分页选择；历史筛选的选中状态与正在查看的结果所属任务分开处理。

执行历史将每次运行的时间、任务、执行状态、完整评分版本标识及操作保留在同一条目内。宽屏按列对齐，窄屏纵向排列，设置基线或打开原始运行时不必把对应身份信息滚出视野。不同宽度保留同一组 DOM 控件。选择结果与选择比较基线分别保留准确的运行和评分版本引用；缺少评分时仍明确显示尚未评分。

宽度在 900px 及以下时，带标签的任务选择器替代桌面任务侧栏，选中的任务包紧随其后。选项使用完整任务名与摘要标识；缺失或有歧义的引用会明确显示。**全部执行历史**只清除任务筛选和历史分页，保留独立选择的结果与基线。**查看执行历史**定位到历史区域，不运行评测。等待历史读取或读取失败时，同一工作区保留的任务元数据仍有明确提示，其他工作区路径不会继承它。缩放窗口时，仅在当前聚焦的任务控件被隐藏后转移焦点。

Loop 实验室是本地数学模拟，与工作区设置和实际运行无关。选择交付方案后，展开**调整模拟**编辑参数草稿，再统一应用。空值、非有限数、超范围数值及非整数的计数字段会显示就地错误，之前的估算结果不变。**重置参数**恢复数值默认值，不修改层配置。层开关会立即使用已应用参数重新计算；不匹配任何预设的组合标为**自定义层配置**，不会错误选中旧预设。所有对比方案使用相同的已应用参数，包括单轮方案中的显式 observe。草稿、已应用参数、层配置和请求选择在当前标签页内跨导航、语言切换保留；刷新浏览器会开始新的实验会话。

窄屏默认折叠参数，先展示估算结果和图表。精确请求编号、上一条/下一条按钮、滑条与图表共享同一选择。SVG 图表随宽度变化而保持高度，在受影响请求之前标出压实，并将历史上下文压实阈值与请求总量分开说明。**累计交付帧 token**统计每次成功交付的帧载荷，不含状态通知，也不因压实而减少；**保留的感知 token**包含仍在上下文中的感知文本、图片及状态通知。请求明细展示本次模拟的实际数值。循环结构和最近模拟历史作为次要内容按需展开。实验室中的操作不会启动模型或改变真实运行。

运行页区分选中的证据、页面自动刷新和最近观察到的宿主状态。全局**回到最新**会清除历史定位及日志筛选，再同时读取观测和日志；**最新日志**只更新当前范围与筛选下的日志。暂停自动刷新会保留当前工作区和运行；主动导航和显式刷新仍可读取一次快照，不会恢复轮询。

运行页先展示观测和活动，再提供次要指标。**运行详情**包含模型、预算与性能数据，**感知与记录详情**包含进程、查询与时空记录。两者默认收起，查询或交付失败仍在观测上方明确提示。单张模型输入图不再重复显示缩略图；多张输入仍可在展开的列表中选择。文字、音频和缺失媒体按内容占用高度。已录制图片与文字读取失败后，可显式重试读取同一资源；音频重试只检查可用性并恢复播放控件，不开始播放。重试保留当前范围和自动刷新设置，不执行感知，也不改变宿主控制权。

活动条目在窄屏下使用完整阅读宽度，来源、类型与状态放在紧凑的标题栏中，复制操作独立显示。复制始终使用完整的已记录文本，即使预览处于折叠状态。长内容可展开并用键盘阅读；更新为较短内容后仍保持可见。复制成功或失败会被辅助技术感知，不改变所选条目。**来源与关联**按需展示完整的已记录来源、追踪字段、事件序号和条目标识。

文档默认跟随界面语言，只有 `docLang=en` 或 `docLang=zh` 才显式固定语言。文档目录与正文使用同一个语言偏好，缺译时明确提示当前回退版本。原生文档链接在普通点击和新标签页中都保留工作区上下文及显式语言。搜索按标题和路径筛选；正文标题链接用 `docAnchor` 保存位置，支持直接访问和浏览器历史。桌面端分别提供文档目录与页内目录；窄屏通过固定的文档工具栏展开两者。代码复制使用渲染器保存的源码文本，保留缩进与内部空行。

宽度在 900px 及以下时，文档侧栏切换为 **文档目录** 菜单；在 1300px 及以下时，页内侧栏切换为 **本页目录** 菜单。每个侧栏与替代入口共用包含边界值的断点。缩放窗口使当前导航控件隐藏时，焦点会转到对应的可见入口。已打开的目录在缩放时保持打开；关闭后将焦点交还可见的触发按钮或对应侧栏。选择文档或标题仍聚焦阅读位置，缩放不会改变搜索草稿、工作区或语言。

目录弹窗的标题与唯一关闭按钮位于滚动内容区之外。说明、完整文档标题、搜索和目录链接在内容区内滚动，让短窗口中的固定标题栏保持紧凑。键盘导航会把到达的条目滚入可见区域；从末项循环到关闭按钮时，该按钮保持可见，无需滚动整个弹窗。

文档、能力与感知设置在读取失败后提供显式重试。刷新失败仍保留上次内容；驱动验证结果和未保存的感知修改与 GET 状态分开管理。工作区目录读取失败显示错误，不会伪装成空工作区列表。重试读取不会重复写入，感知设置保存成功后的值优先于此前发出的读取。

回放分别管理播放采样和事件查看。播放按有界的 30 秒窗口加载画面，画面 API 每次最多接受 60 秒；事件窗口可扩展至 15 分钟，不扩大画面加载范围。精确已过时间输入、前后十秒跳转与进度条都在所选运行或周期内定位。缺失采样与录像缺口保持可见，不得用较晚画面充当较早时刻的证据。

回放工具栏的 **查找事件** 打开现有事件标签并聚焦搜索框，不执行搜索、不改变播放状态或时间，也不清除查询、结果和证据选择。结果条目在完整事件标题上方集中显示已过时间、类型和状态，长文本自然换行。用户明确切回事件标签后，窗口宽度变化会保留该选择；新选中的证据仍会打开详情，当前处于详情时则按需在侧栏与弹窗之间切换。

回放事件搜索通过服务端现有归档索引读取整个所选运行或周期。搜索按不区分大小写的字面文字匹配标题、状态、事件类型及标识符，可按轨道筛选；不搜索任意载荷，也不展开附件。每次响应最多扫描 500 条候选事件、返回 100 条匹配。界面会自动越过无匹配的扫描页，支持取消与重试，并限制当前展示的结果批次大小。游标将查询及范围绑定到源代次和固定事件快照：追加事件需重新搜索，源文件重写会使旧游标失效。扫描完该快照与完成整个归档的索引是两件事；只有 `scan.complete` 与 `coverage.complete` 同时成立，才能声称结果完整或明确没有匹配。

回放证据链接保留工作区、运行、周期和时间，以及 `replayItem`，或 `replayRecord` 与 `replaySequence`。原生链接支持新标签页和浏览器历史。详情展示已记录的标识符、时间、状态、原文，以及确有记录的模型输入；缺失的输入媒体不会被邻近截图替代。截断文本明确标为节选，完整记录仍可在原始数据折叠区查看。无效或不可用的引用保持明确可见。定位、搜索、复制链接、读取详情与重试读取都不会启动驱动、模型或游戏，也不会改变宿主控制权。

回放证据使用紧凑的 **录制证据** 标题栏，并固定显示 **关闭** 操作。完整标题、录制原文、精确输入和元信息在内容区内滚动，长记录与延迟载入的图片不会把关闭按钮推离视口。来源标识与原始 JSON 默认折叠。切换证据后从内容顶部开始阅读；关闭时保留播放位置，并在可用时将焦点交还打开入口，直接链接则使用导航控件作为回退。

## 交互约定

- 表单控件关联 `Label`，帮助信息通过 `aria-describedby` 关联。图标按钮必须有可访问名称。
- 对话框必须有标题和说明，打开时聚焦第一个有用的输入；取消后返回触发按钮，创建成功后聚焦结果。正在创建时保持进度可见，避免意外关闭。
- 明确按钮的 `type`；原生表单的提交按钮用 `submit`，其他操作用 `button`。
- `NativeSelect` 保留原生选项、空值和键盘行为；离散开关用 `Switch`，数值范围用 `Slider`。
- 请求详情使用共享 `Tabs`，支持方向键、Home 与 End；未激活面板不挂载。
- 整行证据与时间轴点击区域可保留显式类型、可见键盘焦点的原生按钮。回放进度条保留原生 range，维持连续毫秒定位及指针／按键释放时提交 URL 的行为；隐藏的声音文件输入也保留原生实现。
- 有后端写入的滑块用 `onValueChange` 更新本地值，`onValueCommit` 保存，避免拖动过程中连续请求。
- 业务请求、等待态、错误反馈与桌面能力检测由页面维护，UI 原语只负责展示和交互。

验收使用 `npm run typecheck`、`npm test`、`npm run build`，并在隔离的 `LUDENS_HOME` 下检查页面与表单操作。详见[控制台调试与验证](../tutorials/debugging-and-verification.md)。
